## 按键与停止

| 按键 | 请求 | 生效条件 |
|---|---|---|
| F1 | 静止校准 | 实际CL_IDLE、四路CCR为0、先收到按键释放的心跳 |
| F2 | 启动闭环 | 新按键事件、无线有效、姿态/标定/ToF/输出保护符合条件 |
| F3 | 降落 | 活动状态逐步降低目标并停止；重复包不重置降落计时 |
| F4 | 急停/清故障 | 保持最高优先级；后续须释放按键并重新按F2 |
| 板载KEY1/KEY2 | 停止 | 保留原独立输出保护 |

F1不是此前固定50%测试版的启转键。重复F1/F2不重复校准/启动。
启动或回连时按键已按住不启动；失联或发射端重启锁住控制资格，需F4复位。
有效会话内旧序号/旧时间先拒绝，旧STOP不能解除故障锁。
解析器允许250ms跨无线包分字节等待；控制有效期仍300ms，使用最后CRC字节的ISR到达时间。
UART错误/队列溢出仍立即Trip，PWM20ms主循环看门狗和90%上限保留。

## 串口（由操作者自己启动）

DAP主机814dc35a，当前`/dev/ttyACM0`，JP13 USART2为115200/8N1；USART1只接遥控，
启动时临时进入配置模式确认C2 UART9600/RF50k，正常工作不从此口发送日志。
KEY/CL/FAULT使用USART2异步发送，不把阻塞逐帧打印搬进控制循环。

默认显示按键和厘米单位的ToF测距高度（模块到下方地面/桌面的距离，尚未扣安装偏移）：

```bash

```

无效测距明确显示“无效”，不把无效原始值当作有效高度；纯按键模式可加`--keys-only`。
这些显示只使用已有`tof/valid/mm`字段，无需重新烧录。

台架验证需要同时看状态、姿态、距离和PWM，加`--full`：


不能把收到按键等同于已经执行起飞。

## 先做USB-only检查

保持桨已拆、动力电池拔掉，放平静置；模块下方留实际约8～12cm、正对有纹理的桌面，
使ToF有新鲜有效数据。此高度仅用于拆桨台架观察高度环，不是地面起飞前置条件。
地面1～2cm近距无效时，通信/status=9新鲜且姿态满足条件即可进入state=1离地段；F4先清旧故障，再新按F2。

1. 打开遥控器，观察CL的link=1、imu=1、tof=1、valid=1、ready=1、PWM四路0。
2. 按F1，等待约2秒；校准完成后姿态持续有效、armlevel=1。
3. 按F2，看KEY收到请求，state由0进入1/2/3，PWM需求非零且全部≤900千分数。
   电池未接时不以是否转动判定软件状态。
4. 按F4，state回0、fault回0、四路PWM为0；继续心跳或重连不能自行恢复非零PWM。

state：0等待、1离地段、2升高目标、3保持目标、4降落、5故障。
state3只是控制器目标状态，不证明飞机已经离地或达到目标。
fault：3失联、4循环超时、5倾角、6测距、7离地超时、8启动条件、9输出保护、
10降落超时、11IMU、12高度输入；其他码见closed_loop.h。
近地无有效ToF时，离地段2秒后fault7停机仍是预期保护，不伪造高度、不去掉保护。

## 随后的拆桨电机检查

USB-only按键和停止检查通过后，再由操作者接动力电池。
以已确认的新机头方向：M1右前顺、M2左前逆、M3右后逆、M6左后顺（俯视）。
启动前机身平稳；启动后轻微左右/前后倾斜，核对roll/pitch与对应电机差速方向，
保持小于25°，触及25°会故障停机。F4始终可停止，停止后须新F2事件。
拆桨只验证输出与差速方向，实际恢复力矩/悬停需以后按比赛系绳要求单独验收。

ToF目标暂沿用台架20cm传感器距离，尚未换成离地40cm任务。
光流继续真实读取，CL_FLOW_AXES_VERIFIED=0，未启用横向控制；后续还要实机标定方向/比例。
90%/90%是操作者要求的起飞试验参数，尚未标定为真实悬停推力，当前不能据此宣称比赛飞行通过。
