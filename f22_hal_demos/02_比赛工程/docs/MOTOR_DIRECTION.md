# 电机旋向检查（历史配置）

当前已切换[拆桨姿态差速台架](ATTITUDE_CHECK.md)，下面保留5%旋向诊断的历史行为，不是当前板上模式。

此前临时烧入环境为 `contest_motor_direction`，固件 `firmware/contest_motor_direction_pwm5_imu_mount_fix.bin`，38684字节。[完整备份、测试和烧录读回](validation/imu-mount-fix-2026-10-15/manifest.json)。本版将IMU水平参考修正为 `(-sensorY,-sensorX,-sensorZ)`；用户烧录后口述确认方向正确，动态角速度/实际扶正力矩仍待验收。飞行主线环境保留此前90%源码，现板上已替换为20%上限姿态台架。

你已实际观察电机，并在记录中写明每个位置的桨叶字母和旋向。历史5%诊断四路同速输出，只用于观察转向，不验证姿态扶正力矩。程序不自动施加更大的启动脉冲。

- 上电四路为0；松开遥控按键、链路就绪后，新按F2，M1/M2/M3/M6均固定5%。
- F3/F4立即停止；F4可清故障，重新启动须再次新按F2。板载停止和失联/输出看门狗仍保留。
- 活动时state=3仅表示诊断输出保持；PWM四路应为 `50,50,50,50` 千分数，停止为 `0,0,0,0`。
- 不使用IMU、ToF或起飞超时作为旋向诊断门限，仍会输出传感器日志。此版本不能起飞、定高或降落。

按你刚发的 `fly2.md` 记录，机头方向下的位置、桨叶字母和从上方看旋向如下。字母对应按这份记录使用：L 配逆时针，R 配顺时针。

| 位置 | 接口 | 桨叶字母 | 俯视旋向 |
|---|---|---|---|
| 右前 | M1 | R | 顺时针 |
| 左前 | M2 | L | 逆时针 |
| 右后 | M3 | L | 逆时针 |
| 左后 | M6 | R | 顺时针 |

这与当前 M1/M2/M3/M6 固件映射一致。仓库归档中的早期 `fly2.md` 记录了另一套 M1～M4 布局；上表按你最新发来的记录执行，不用归档旧表替代。

构建：`pio run -e contest_motor_direction`。串口继续使用现有 `scripts/show_remote_keys.py`，JP13/DAP为115200；只启动一个监视器。后续恢复飞行配置须明确重新构建/烧录飞行环境并核对hash，不能把低占空比诊断当作起飞版。
