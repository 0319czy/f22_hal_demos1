# 拆桨姿态差速检查

环境 `contest_attitude_check_jp13`，入口 `src/main.c`，台架状态机 `src/bench/attitude_check.c`，共用飞行姿态/角速度控制与混控 `ClosedLoop_AttitudeMix`。固件 `firmware/contest_attitude_check_jp13_pwm20.bin`；[构建、烧录与读回记录](validation/attitude-check20-2026-10-15/manifest.json)。这一步验证传感器到PWM需求的方向，不能作为真实扶正或起飞验收。

本版修正后的机体映射仍为 `(-sensorY,-sensorX,-sensorZ)`，加速度与陀螺仪使用相同旋转。仅显式台架环境允许此轮检查，历史飞行环境的轴向许可仍为0，新增显式系绳试验环境使用本轮已确认的静态方向。

## 按键与行为

- 上电四路PWM0，不自动启动。F1只在空闲且输出全0时进行静止校准。
- F2从平放状态启动，基础需求以每秒10个百分点缓升，约1.5秒到15%；姿态/角速度反馈在缓升过程中就参与差速，每路硬上限20%（串口200‰）。
- F3、F4立即停止；F4清故障，重新启动需新的F2事件。放开F2后继续运行台架反馈。
- 启动需有效IMU、遥控链路、姿态收敛、接近水平及小角速度；运行时IMU失效、失联、循环异常、单轴倾角达到25°或输出保护会锁存故障并清零。板载停止键及20ms输出看门狗保留。
- ToF和光流继续显示，台架控制不使用它们；不伪造高度，不进入起飞/定高/落地流程，不设置两秒离地超时。因此桌面近距测距无效不妨碍本轮差速检查。总线阻塞仍可能触发保留的循环/输出保护。
- `state=3`表示拆桨台架反馈运行，日志带 `bench=attitude20`；默认显示脚本会标注“模式=拆桨姿态差速”。这不是悬停状态的实飞证明。

## 操作顺序

1. 保持拆桨、动力电池拔掉，只用USB供电。飞机放平、垫稳，等待IMU=1、校准=1。
2. 沿用DAP串口显示命令，打开遥控器并等待链路就绪：

   ```bash
   /home/czy/.platformio/penv/bin/python -u /home/czy/f22_hal_demos1/f22_hal_demos/02_比赛工程/scripts/show_remote_keys.py
   ```

3. 等“遥控=1、就绪=1”；若为故障状态，先F4。平放时按一次F2，等待约2秒。应有非零PWM需求，`state=3 fault=0`，所有值均不超过200。只有USB供电时这些是控制/定时器需求，不代表电机有动力。
4. 每次回平放后只改变一个方向，倾斜约10°、停住约2秒再取一行日志。运动瞬间的角速度阻尼会改变需求，因此比较停住后的数值。

| 姿势（按飞机自身前后，M1右前/M2左前/M3右后/M6左后） | 预期角度 | 停住后的PWM关系 |
|---|---|---|
| M1/M3侧压低，左高右低 | 横滚正 | M1>M2，M3>M6 |
| M2/M6侧压低，右高左低 | 横滚负 | M2>M1，M6>M3 |
| M1/M2前侧压低，前低后高 | 俯仰负 | M1>M3，M2>M6 |
| M3/M6后侧压低，前高后低 | 俯仰正 | M3>M1，M6>M2 |

5. F4后四路应立即全0。保存“平放、右低、左低、前低、后低、F4后”的带标签日志，先核对方向，再进行无桨动力转速响应测试。

## 验证边界

主机测试运行真实台架状态机、共用混控和PWM驱动寄存器替身，检查角度误差/角速度阻尼方向、15%基础/20%限幅、无有效ToF持续超过2秒、停止、故障锁存与驱动看门狗；七环境构建检查本台架只链接姿态反馈，不链接飞行起降状态机。合成输入与寄存器替身不验证实物电气、实际转速、推力或飞行。

## 最新操作反馈与下一步

操作者先确认右低/前低的PWM关系，再确认这两个姿势的对应电机实际加速，最后对左低/机尾低和F4实际全停回复“对的”。本轮四方向静态拆桨差速及实际停转记为操作者口述通过；未提供测速或原始串口记录，动态反馈、带桨扶正力矩和实飞尚未验收。记录：[PWM确认](validation/attitude-check20-2026-10-15/operator-pwm-confirmation.json)、[电机响应](validation/attitude-check20-2026-10-15/operator-motor-confirmation.json)、[本轮完成](validation/attitude-check20-2026-10-15/operator-bench-completion.json)。

随后操作者对停转、拔动力电池后，水平抬高到目测约10/20/40cm的测距检查回复“这个也是对的”。记录为ToF有效性、抬高趋势和停住稳定的定性通过，见[测距反馈](validation/attitude-check20-2026-10-15/operator-tof-confirmation.json)；无尺距/数值记录，不作为精度标定或长期稳定性验收。桌面近距无效不算模块损坏。
