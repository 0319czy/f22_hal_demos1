# 比赛板 IMU 单独检查

环境 `contest_imu_check` 使用比赛程序同一 `ImuCalibration` 算法，隔离光流/ToF、任务状态机和动力。只接USB，固定静止启动；约0.5秒100样本通过稳定性检查后，输出已扣零偏的角速度。失败每2秒重试，重新固定后可恢复；启动和重校准期间暂不输出数据。

```bash
pio run -e contest_imu_check
```

本环境不链接电机PWM。默认比赛环境仍为 `contest_hover`，下载任一环境会替换板上固件。当前板A的自动复位需要已记录的ROM GO时序，不能把旧板下载电平视为通用；检查接线、板身份和端口再下载。

VOFA导入 [imu_check.csv](../imu_check.csv)，板载USB串口115200 8N1 / JustFloat。与主比赛环境的32通道/UART4遥测不同，不能混用模板；CH340与E49共用USART1，本程序不测试遥控，不向串口发送操作文字。

| 通道 | 名称与单位 |
|---|---|
| 0 | imu_ok：本帧读取成功且启动校准通过 |
| 1～3 | acc_x/y/z，g，传感器轴 |
| 4～6 | gyro_x/y/z，°/s，扣零偏后 |
| 7～8 | IMU温度℃、加速度模长g |
| 9～11 | bias_x/y/z，°/s，原始角速度零偏 |
| 12 | 当前校准窗口成功采样数，完整窗口100 |
| 13 | IMU采样通信错误累计数 |
| 14 | 输出采样间隔ms，校准期间会暂停 |
| 15 | 校准失败累计数，不代表当前仍失败 |

CH0=0时测量CH1～8为NaN，bias可能是此前成功值，不能继续视为有效测量。CH0=1只证明校准门限与本帧通信合格，不能证明板子绝对静止、机体安装方向已确认或可以起飞。恒定慢速yaw旋转可能被估计为零偏，必须人为固定静止。本程序没有姿态闭环、电机控制或六面加速度校准。
