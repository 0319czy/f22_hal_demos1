# 比赛规则与实现

当前目标：飞行巡航定点赛V5.0悬停组。依据[实施方案2026.7](references/比赛实施方案_2026.7.pdf)第9～13页；规则及逐项实施进度统一维护在[PROJECT_PLAN](../PROJECT_PLAN.md)。

核心要求：红圈起飞；无线一键起飞后自主控制；20～100cm保持5秒以上；一键降落；全程不超过1m；约1.5m系绳可靠连重物。中心红圈500分，外侧每环少20分，可直接看清中心标记与落环关系加20分。

当前主线是contest_aircraft1_radio_v2_jp13。20cm传感器目标距离、8°启动角、12cm起始距离、90%PWM试验上限及2秒离地超时是开发参数；此前实测版本为15%/20%，40cm/6秒为计划的实飞验收目标，不是原文额外规定。ToF距离要结合安装高度/地面基线理解，不能把传感器目标值直接当成已满足裁判高度。

实际离地、光流水平定点和落环尚未验收。光流不能直接识别红圈；六轴姿态相对航向及光流积分会漂移。后续赛事通知、器材型号/电池合规和裁判高度参考仍应在赛前确认。
