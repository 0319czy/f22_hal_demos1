# M1～M4 同时 15% PWM 直接台架

源码：`src/bench/motor_m1234_pwm15.c`。环境：`contest_motor_m1234_pwm15`。
已编译 BIN：`firmware/contest_motor_m1234_pwm15.bin`。

程序启动后先保持电机输出低电平，等待 2 秒，再同时输出四路高有效 PWM。
M1/2/3/4 分别是 PC6/7/8/9，对应 TIM3 CH1/2/3/4 完全重映射。
TIM3 时钟 72MHz，PSC=23、ARR=199、CCR1～4=30，设计频率 15kHz、占空比 30/200=15%。
占空比是定时器配置，尚未通过示波器确认，也未烧录本固件验证电机运行。

KEY2 在等待期间按下会取消启动；运行期间按下会锁定停止，松手不会重新启动，复位会重新进入启动流程。
该入口不等待遥控命令，不读取姿态，也不是飞行控制器。烧录后程序启动会自动驱动电机，应拆桨使用。

在比赛目录构建：

```bash
pio run -e contest_motor_m1234_pwm15
```

2026-10-11 构建 SUCCESS，退出码 0；源码差异检查通过。现有四路 `contest_motor_quad_direct` 是全直流输出，不符合 PWM 15% 要求，故保留它并新增此独立入口。
